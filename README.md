# Aguiar.dev Portfolio

A cozy lofi personal portfolio built with plain HTML, CSS, and JavaScript.

This project presents my learning journey across software development, cybersecurity, technical support, automation, and study notes. The visual direction combines a warm cafe atmosphere with a subtle retro-computer interface, creating a portfolio that feels personal, technical, and easy to navigate.

## Why This Project Exists

The goal of this portfolio is to show practical growth instead of only listing technologies. It includes projects, skills, experience, certificates, notes, and a small interactive lofi player to reflect the study-focused identity behind the site.

The site is intentionally simple and static so it can stay fast, easy to maintain, and easy to deploy.

## Built With

- **HTML5** for semantic structure and accessible content.
- **CSS3** for layout, responsive design, animations, glassmorphism, and the retro cafe visual system.
- **Vanilla JavaScript** for interactivity without framework overhead.
- **Web Audio API** for a generated lofi loop directly in the browser.
- **Intersection Observer API** for lightweight fade-in animations.
- **Google Fonts** using `Space Grotesk` for the main interface and `Fira Code` for technical/retro elements.

## Why These Technologies

This portfolio does not use React, Next.js, Tailwind, Bootstrap, or any frontend framework. That decision keeps the project small, transparent, and focused on fundamentals.

Using vanilla HTML, CSS, and JavaScript makes the code easier to inspect, understand, and evolve. It also shows direct knowledge of browser APIs, responsive layout, accessibility practices, and DOM-based interaction.

## Features

- Responsive single-page portfolio
- English and Portuguese language toggle
- Sticky navigation with mobile hamburger menu
- Cozy retro cafe visual style
- Live clock and date widgets
- Animated retro monitor face
- Interactive generated lofi player
- Skills section with development, cybersecurity, languages, and soft skills
- Study notes section with blog-style note pages
- Certificates section with external links
- Experience timeline
- GitHub project cards linked to selected repositories
- Contact section with social links and simulated form submission
- Accessible focus states and reduced-motion support

## Design Direction

The interface is inspired by:

- cozy lofi study rooms
- warm cafe lighting
- older computer dashboards
- minimal technical portfolios
- readable documentation and study notes

The goal is to feel approachable and focused without looking like a fake hacker theme.

## Accessibility and Responsiveness

The site includes:

- semantic HTML sections
- skip link
- visible keyboard focus states
- ARIA attributes for interactive controls
- responsive mobile-first layout
- reduced-motion media query
- clear color contrast for dark mode

## Current Status

This is the first polished static version of the portfolio. It is ready for personal presentation and can be extended with real blog posts, more certificates, project pages, and a real contact form integration.
